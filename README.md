`Python` `Deep Learning` `DenseNet121` `LLaMA 3` `LangChain` `LangGraph` `Grad-CAM` `Streamlit`

**Results:**

* 📈 AUC: **0.998**
* 🔍 Recall: **99.5%**

🔗 [View Project](https://github.com/mariembenattia12/diagnovision)
